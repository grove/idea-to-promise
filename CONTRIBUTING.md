# Contributing

Start with [AGENTS.md](AGENTS.md) and [the discovery protocol](docs/discovery-protocol.md).

Keep changes focused on the Idea to Promise boundary. A new feature should improve framing, alternative generation, decision-directed research, promise shaping, or the handoff to Promise to Proof without duplicating P2P's acceptance/delivery responsibilities.

When changing a skill, preserve the separation between evidence, recommendation, human decision, exact promise approval, and implementation authority.
