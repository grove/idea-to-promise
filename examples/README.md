# Worked discovery examples

New to ITP? Read the [5-minute Getting Started guide](../docs/getting-started.md) first. These examples are useful once you want to see how different discovery outcomes look in more detail.

Every example is fictional authored teaching material—not a live-agent test,
customer observation, experiment result or real human approval.

| Example | Useful lesson |
|---|---|
| [Quick export improvement](quick-export.md) | Reuse supplied choices; one notebook can be enough |
| [A bad feature idea](bad-feature.md) | Reject a solution that misses the actual need |
| [Experiment-first architecture](experiment-first.md) | Choose learning without promising a favorable result |
| [An existing solution](existing-solution.md) | Finish without building a duplicate capability |
| [Challenge changes the choice](challenge-changes-choice.md) | Preserve history and let the human amend the decision |
| [Revisit and portable handoff](revisit-and-handoff.md) | Preserve approved scope and transfer real approval evidence |

The [export draft](export-promise.md) is also a real Markdown fixture for the
structural checker. It is deliberately not accompanied by a real approval.
Behavioral trials and review belong in the separate [evaluation kit](../evaluations/README.md).
